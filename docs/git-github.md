# Git và GitHub trong quản lý phiên bản phần mềm
## 1. Khái niệm Git
Git là hệ thống quản lý phiên bản phân tán (Distributed Version Control System - DVCS) được sử dụng để theo dõi các thay đổi trong mã nguồn và hỗ trợ làm việc nhóm hiệu quả.

## 2. Khái niệm GitHub
GitHub là nền tảng lưu trữ mã nguồn trực tuyến dựa trên Git, cung cấp các tính năng quản lý dự án, cộng tác nhóm và kiểm soát phiên bản.

## 3. Vai trò của Git và GitHub
* Theo dõi lịch sử thay đổi của dự án.
* Hỗ trợ nhiều người cùng phát triển phần mềm.
* Khôi phục các phiên bản trước khi cần thiết.
* Quản lý và lưu trữ mã nguồn tập trung.

## 4. Các lệnh Git cơ bản
* git init
* git clone
* git add
* git commit
* git push
* git pull
* git branch
* git merge

## 5. Quy trình làm việc với GitHub
1. Tạo repository.
2. Clone repository về máy.
3. Tạo branch mới để phát triển tính năng.
4. Commit các thay đổi.
5. Push lên GitHub.
6. Tạo Pull Request.
7. Review và Merge vào nhánh chính.
