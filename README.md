# My Project - Dự án mẫu

##Giới thiệu
Đây là dự án mẫu thể hiện cấu trúc chuẩn của một ứng dụng phần mềm.

##Cài đặt và chạy

\`\`\`bash
git clone <url-repo>
cd my-project
npm install
npm start
\`\`\`

##Chạy kiểm thử

\`\`\`bash
npm test
\`\`\`

##Cấu trúc thư mục

| Thư mục | Chức năng |
|---------|-----------|
| `src/`  | Mã nguồn chính |
| `tests/`| Kiểm thử |
| `docs/` | Tài liệu |
| `scripts/` | Script tự động hóa |
| `.github/` | CI/CD |
